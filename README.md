# 康威生命游戏（Conway's Game of Life）

一个用 HTML + CSS + 原生 JavaScript 实现的单页康威生命游戏。  
全屏网格、编辑模式、速度调节、示例动画和实时统计。

## 在线演示

https://github.com/Airsherry/ConwayGame/life-game.html

## 功能

- 全屏 Canvas 网格，沉浸式体验
- 开始  暂停  继续游戏
- 编辑模式：点击或拖动可创造  消除细胞
- 动画速度调节
- 实时统计：存活细胞数、细胞路径面积、代数、当前状态
- 游戏规则弹窗
- 示例动画：滑翔机、脉冲星、高斯帕滑翔机枪等
- 全部死亡时自动暂停并提示

## 游戏规则

每个细胞周围有 8 个邻居，边界外视为死亡细胞。每一代同时更新：

- 活细胞周围活邻居少于 2 个：死亡（孤独）
- 活细胞周围有 2 或 3 个活邻居：继续存活
- 活细胞周围超过 3 个活邻居：死亡（拥挤）
- 死细胞周围恰好有 3 个活邻居：繁殖，变成活细胞

## 操作说明

- 点击“开始游戏”：开始演化
- 点击“暂停”：暂停演化
- 点击“编辑模式”：进入编辑模式，点击或拖动切换细胞状态
- 拖动速度滑块：调整动画速度
- 点击“游戏规则”：查看规则说明
- 点击“示例动画”：加载经典初始图案
